# Architecture decision records

Each file records one decision: the context that forced it, what was chosen, the alternatives
rejected and the consequences. Records keep the reasoning of their date; a later record that
supersedes or amends one takes precedence, and the status line says so. Code comments cite records
by number (`ADR-080`), so numbers never change and are never reused.

Add a record when the project changes direction or when a future maintainer would ask "why is it
like this?". Copy [template.md](template.md) to the next free number, `NNN-short-title.md`, and add
it to the table below.

Status values: **Accepted** (current direction), **Superseded** (replaced by a later record, named
in the status), **Proposed** (not final). "Accepted" records a decision; it does not prove a test
run, release or deployment.
